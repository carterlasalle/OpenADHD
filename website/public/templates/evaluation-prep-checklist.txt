EVALUATION PREP CHECKLIST

GOAL OF THIS APPOINTMENT
[ ] Do I want diagnostic clarity, treatment planning, or both?

EXAMPLES TO BRING
[ ] Attention / distractibility example
[ ] Task initiation / procrastination example
[ ] Time blindness / lateness example
[ ] Organization / losing things example
[ ] Emotional regulation / overwhelm example
[ ] School, work, or relationship impact example

TIMELINE NOTES
[ ] Childhood signs I remember
[ ] Teen or college patterns
[ ] Current adult patterns
[ ] What got worse recently
[ ] What already helps a little

QUESTIONS FOR THE CLINICIAN
[ ] What does the evaluation process include?
[ ] How do you assess overlap with anxiety, depression, trauma, or sleep issues?
[ ] What records or forms should I bring?
[ ] What happens after the evaluation?
[ ] What are typical next treatment options if ADHD is confirmed?

LOGISTICS
[ ] Confirm appointment date and time
[ ] Confirm cost / insurance / payment plan
[ ] Ask whether forms must be completed in advance
[ ] Set two reminders for the appointment

ONE-SENTENCE OPENING SCRIPT
"I want to be evaluated because I have repeated problems with attention, time management, follow-through, and daily functioning across multiple settings."

AFTER THE APPOINTMENT
[ ] Write down what the clinician said
[ ] Save paperwork in one folder
[ ] Record next steps before leaving the office or call
